# Roadmap Estratégico: Feira Fácil SaaS

Este documento mapeia a evolução do aplicativo Feira Fácil de um projeto de testes para um produto SaaS (Software as a Service) monetizável.

## 1. Funcionalidades Atuais (Core)
*   **Gestão de Grupos:** Sincronização em tempo real entre casais/famílias.
*   **Comparativo Inteligente:** Motor que sugere em qual mercado comprar cada item para economizar.
*   **Preços Progressivos:** Suporte a valores de atacado (ex: "leve 3 pague menos").
*   **Modo de Compra:** Check-list interativo para uso dentro do mercado.
*   **Conformidade LGPD:** Telas legais e fluxo de exclusão de dados.

## 2. Funcionalidades Faltantes para SaaS
*   **Camada de Assinatura:** Integração com RevenueCat/Stripe para planos mensais/anuais.
*   **Automação de Entrada (OCR):** Scanner de notas fiscais para atualizar preços automaticamente via foto.
*   **Analytics de Gastos:** Gráficos de evolução de preços e inflação pessoal por categoria.
*   **Alertas de Orçamento:** Notificações push quando a lista ultrapassa o teto definido.
*   **Gestão de Estoque:** Controle de despensa para sugerir itens que estão acabando.

## 3. Divisão do Modelo Freemium

### Plano Free (Gratuito)
*   Uso em 1 único grupo familiar.
*   Comparação manual de preços.
*   Até 3 listas ativas.
*   Suporte a anúncios (opcional).

### Plano Premium (Pro/SaaS)
*   **OCR Ilimitado:** Cadastrar preços apenas tirando foto da nota.
*   **Grupos Ilimitados:** Ideal para quem cuida de várias casas (ex: casa própria + casa dos pais).
*   **Histórico Completo:** Acesso a dados de variação de preços de todo o período.
*   **Exportação de Dados:** Salvar comparativos em PDF ou Excel.
*   **Análise de Economia:** Relatório mensal de quanto o app ajudou a poupar.

## 4. Próximos Passos (Fase de Testes com Casais)
1.  **Feedback de Velocidade:** Medir quanto tempo os casais levam para cadastrar uma feira completa.
2.  **Validação de Valor:** Perguntar após 1 mês: "Quanto você pagaria para não ter que digitar esses preços?" (Isso valida o OCR como feature Pro).
3.  **Ajustes de UX:** Simplificar a troca de mercados durante o modo de compra.
